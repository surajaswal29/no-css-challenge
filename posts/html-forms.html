Why forms matter

Forms are how a page listens: sign-ups, searches, orders and messages. HTML gives you labelled controls, keyboard support and validation for free. Every example on this page works without a line of JavaScript.

The basic structure

<form action="/subscribe"
      method="post">
  <label for="email">Email</label>
  <input type="email" id="email"
         name="email" required>
  <button type="submit">
    Subscribe</button>
</form>

The for attribute ties a label to its control, so clicking the words focuses the field and screen readers read them aloud.

Good habits

  • Label every control, and keep the label visible
  • Group related controls with <fieldset> and <legend>
  • Choose the most specific type
  • Add autocomplete so browsers can fill in known details
  • Validate with attributes first; the server should still check everything
Try it yourself

Write an input for a four-digit PIN that is required and only accepts digits.

Show the solution

<label for="pin">PIN</label>
<input id="pin" name="pin"
       inputmode="numeric"
       pattern="[0-9]{4}"
       maxlength="4" required>
