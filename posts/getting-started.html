What is HTML?

HTML, the HyperTextFootnote 1. Hypertext is text with links in it. The word was coined by Ted Nelson in the 1960s, decades before the web. Markup Language, is how every web page describes its content. It says this is a heading, this is a paragraph, this is a link, and the browser does the rest.

Because it is the first thing a browser receives, a page built only from HTML is the fastest page you can make.

The shape of every page

Every HTML document follows the same simple outline:

index.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My first page</title>
  </head>
  <body bgcolor="#F5F2EB"
        text="#3D4A48">
    <h1>Hello, quiet web</h1>
    <p>My very first paragraph.</p>
  </body>
</html>

Download this page as a file and open it in your browser to see it for yourself.

Headings and text

HTML has six levels of heading, from <h1> for the page title to <h6> for the smallest subheading. Use them in order, like the outline of a book.

Inside a paragraph you can mark words with meaning:

  • bold with <b>, and important with <strong>
  • italic with <i>, and emphasis with <em>
  • highlighted with <mark>
  • keyboard keys like Ctrl+C with <kbd>
  • H2O and E = mc2 with <sub> and <sup>
  • old words new words with <del> and <ins>
  • short quotes like less, but better with <q>
  • abbreviations like HTML with <abbr> (hover it)

Links and images

A link is an <a> element with an href. It can point to another site, another page, a spot on the same page (like this one), an email address or a file to download.

<a href="about.html">About me</a>
<a href="#lists">Jump to lists</a>
<a href="report.pdf" download>
  Get the report</a>

Images need an alt description for people who cannot see them, and a width and height so the page does not jump while they load:

<img src="lake.jpg"
     alt="A still lake at dawn"
     width="600" height="400"
     loading="lazy">
Tip
loading="lazy" tells the browser to wait until an image is close to the screen before downloading it. One attribute, and long pages load noticeably faster.

Lists

Unordered lists use <ul>, and type changes the bullet:

  • Morning tea
  • A short walk
  • One good page of writing

Ordered lists use <ol>. They can count in Roman numerals, or backwards:

  1. Write the structure
  2. Fill in the words
  3. Read it aloud
  1. Three
  2. Two
  3. One. Breathe out.

And description lists pair terms with their meaning:

Element
A piece of the page, such as a paragraph.
Attribute
Extra information on an element, such as href.

Good habits

  • Always start with <!DOCTYPE html> and a lang attribute
  • Give every page a clear <title> and a meta description
  • Use headings in order, and one <h1> per page
  • Describe every meaningful image with alt
  • Check your page with the keyboard alone
Try it yourself

Make a page with a heading, a short paragraph and a list of three things that make you calm.

Show the solution

<h1>Things that calm me</h1>
<p>A short list for slow days.</p>
<ul>
  <li>Rain on the window</li>
  <li>A warm drink</li>
  <li>A quiet page</li>
</ul>
